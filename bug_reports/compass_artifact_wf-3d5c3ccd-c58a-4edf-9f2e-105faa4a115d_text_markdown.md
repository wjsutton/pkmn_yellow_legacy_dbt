# Pokemon Yellow Legacy Validation Guide: Complete Checkpoint Reference

Pokemon Yellow Legacy by TheSmithPlays and cRz Shadows transforms the original Yellow with **20 years of hindsight**, featuring dynamic gym scaling, buffed underused Pokemon, fixed type effectiveness (Ghost now beats Psychic), and trade evolutions converted to level-based. This comprehensive validation guide covers all major checkpoints in standard gym order with verified trainer teams, recommended counters, and critical mechanics changes that affect each battle.

## Pre-Brock: Viridian Forest to Pewter City

The early game features significant changes designed to give players more options against Brock's newly buffed team. The **Old Rod is now available in Viridian City Mart** rather than Vermilion, allowing players to fish for Water-types immediately.

**Available Pokemon for Brock:**
- **Viridian Fishing**: Poliwag and Goldeen (both learn Bubble)
- **Route 22**: Mankey (Low Kick at Lv9), Nidoran♂/♀ (Double Kick at Lv12)
- **Viridian Forest**: Caterpie → Butterfree (Confusion at Lv10), Weedle → Beedrill (Pin Missile on evolution), Oddish (new addition)
- **Route 2**: Vulpix (moved from Game Corner)

**Brock's Team:**
| Pokemon | Level | Notes |
|---------|-------|-------|
| Geodude | 10 | Rock/Ground |
| Onix | 12 | **Massively buffed (+125 BST)**: HP 35→75, Atk 45→80, Spc 30→65, Spd 70→95 |

Brock uses only weak Normal-type attacks (Tackle, Bind) with no Rock STAB. The critical change is **Onix's improved Special bulk**, meaning Bubble and Leech Seed are now far less effective than in vanilla Yellow. Bind can be dangerous with RNG luck.

**Community-Recommended Counters:**
1. **Butterfree** (Confusion exploits low Special)
2. **Mankey with Low Kick** (Fighting SE vs Rock/Ground)
3. **Goldeen/Poliwag** (Water STAB; Bubble was nerfed to 10 BP to prevent being overpowered)
4. **Beedrill with Pin Missile** (not resisted by Rock/Ground)

**Hard Mode Level Cap**: ~12 (matching ace level)

## Critical Mechanics Reference

**Evolution Changes (No Trading Required):**
| Pokemon | New Method |
|---------|------------|
| Alakazam | Level 42 |
| Gengar | Level 42 |
| Golem | Level 38 |
| Machamp | Level 38 |
| Poliwhirl | Level 18 (was 25) |

**Major Stat Buffs:**
| Pokemon | Change | Details |
|---------|--------|---------|
| Pikachu | +65 BST | HP 35→60, Def 30→50, Spc 50→70 |
| Onix | +125 BST | HP 35→75, Atk 45→80, Spc 30→65, Spd 70→95 |
| Farfetch'd | +50 BST | All stats +10 |
| Wigglytuff | +45 BST | Def +10, Spc 50→85 |
| Venomoth | +25 BST | Atk +10, Spc +5, Spd +10 |

**Move Power Changes:**
| Move | Old → New | Notes |
|------|-----------|-------|
| Leech Life | 20 → 50 | +30 BP, +10 PP |
| Wing Attack | 35 → 60 | +25 BP |
| Mega Drain | 40 → 65 | +25 BP |
| Solar Beam | 120 → 180 | +60 BP |
| Sludge | 65 → 90 | All Poison-types can learn |
| Pin Missile | 14 → 20 | +15% accuracy |
| Twineedle | 25x2 → 40x2 | +15 BP each hit |
| Dig | 100 → 70 | Nerfed for balance |
| Bubble | 20 → 10 | Nerfed for early game balance |

**Type Effectiveness Changes:**
- **Ghost → Psychic**: Now Super Effective (fixing Gen 1 bug)
- **Bug → Poison**: No longer Super Effective
- **Ghost**: Now Special type (was Physical)
- **Gust**: Now Flying type
- **Cut**: Now Bug type

**Hard Mode Features:**
- Forced Set mode (no free switches)
- Items disabled in battle
- **Level caps by gym** - Pokemon stop gaining EXP at cap until badge obtained
- 1/256 miss chance retained (removed in Normal mode)

**Dynamic Scaling (Gyms 4-6):**
The order you fight Erika, Koga, and Sabrina determines their team levels:
- **Fought 4th**: ~Lv30-35, 4 Pokemon
- **Fought 5th**: ~Lv38-42, 4-5 Pokemon  
- **Fought 6th**: ~Lv47-50, 5 Pokemon
